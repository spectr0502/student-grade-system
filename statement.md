# Project Statement

## Project Title
Student Grade System

## Problem Statement
Calculating total marks, percentage, grade points, and result manually can be repetitive and may lead to mistakes. This project provides a simple program that accepts marks in five subjects, calculates the student's academic summary, displays a report card, and saves the result.

## Scope
The system accepts a student name, roll number, and marks in Mathematics, Physics, Chemistry, Programming, and English. It calculates total marks, percentage, SGPA, and PASS/FAIL status. It stores each report in a CSV file. This is a basic educational implementation and does not include login, a graphical interface, or an institution-specific credit-weighted SGPA formula.

## Target Users
- Students learning Python programming
- Beginners practicing functions, modules, calculations, and CSV handling
- Users who need a simple command-line grade calculator

## High-Level Features
- Collect student details and subject marks
- Validate marks between 0 and 100
- Calculate total, percentage, and SGPA
- Determine PASS/FAIL based on a 40-mark minimum in every subject
- Display a report card
- Save student records in CSV format
